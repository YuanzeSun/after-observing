# 1.1 天文与日历核对

剧情城镇与天气为架空。日期、时区和天体事件依据可核对资料；插画与目镜印象用于叙事，不能当作精密星图。

* 国立天文台：[2026年3月皆既月食](https://www.nao.ac.jp/astro/sky/2026/03-topics02.html)。3月3日，JST约18:50偏食开始，20:04全食开始，20:34最大，21:03全食结束，22:18偏食结束。月球从东侧升起后的方向随地点与时刻变化；剧情不复制东京示意位置当架空城镇实测。家中私下观察与学校十九点半收场是不同安排。月食不能凭剧情承诺必晴。
* NASA：[January 2026 Skywatching Tips](https://science.nasa.gov/solar-system/skywatching/whats-up-january-2026-skywatching-tips-from-nasa/)。1月10日木星冲，一月适合晚间看木星；用作1月5日试办目标的参考。正文不给未经地点星历计算的精确高度，也不保证每次看到的卫星数量相同。
* 日本内阁府：[2026年国民祝日](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)。1月12日、2月11日、2月23日、3月20日等与学校上课/约见时间分开核对。凛2月11日生日不写成正常放学日。虚构学校的具体校历仍由事件册明确。
* 11月28日18:00 JST月面参考沿用已核验的NASA SVS/LRO图像；源、时刻和北向上方向在原项目outputs/月面资料说明.md与原始数据保存。目镜方向取决于器材，不直接等同纸图。

月食资料页为本项目代码绘制的过程示意，按官方时刻标注，不冒充现场摄影，也不按图上大小估计真实角距/亮度。
