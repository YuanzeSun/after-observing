# 1.1.1

针对 issue #5 新增单独的 **CG 解锁补丁**，供希望直接欣赏插画的玩家使用。下载 `AfterObserving-1.1.1-cg-unlock.zip`，退出游戏后把其中的 `game` 文件夹合并到安装目录，重启后打开「回想与鉴赏」→「事件插画」，即可观看全部32张插画。补丁也适用于1.1，包含全部插画剧透。

补丁不含玩家存档，不添加、覆盖或删除存档槽，不改已读章节、路线完成与选项前情。新玩家的读取存档页仍为空；已有存档可继续使用。正常游戏包仍按阅读进度解锁插画。

**`save-baseline.zip` 仅供开发者构建时保留语句标识，不是玩家存档或通关补丁，请勿放进游戏目录。** 发布资产标签与该压缩包内的说明已明确标注用途。

1.1.1沿用1.1的存档目录。请将新版解压到独立文件夹后启动，已有存档与鉴赏记录会继续读取；无需移动或替换存档文件。

Windows与Linux包各自包含游戏运行库和全部素材。请完整解压并保留目录内文件。离线全文、校验和、原生验收证据和存档标识基线同时提供。
