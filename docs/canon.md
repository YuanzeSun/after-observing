# 1.1 人物与事件册

## 世界与共同目标

架空日本地方城镇，县立汐见高中。全年龄，2025年十月至2026年四月。高桥悠介因校刊排版被千夏叫来做观测会海报，第一次真在目镜中辨出两颗颜色不同的星。第二章正式入部。大家要在三月21日办一次有外部来访者的公开观测；先学着让别人看见，渐渐也承认自己想看、想待在谁身边。

天气不承诺必晴，公开活动有观测与阴天演示/记录展示两套方案；不靠最后一秒天开制造人物成长。校内夜间活动申请，顾问在场，十九点半原则收工。电路/维修限低压与机械固定，复杂改动由老师检查，不写儿童冒险攀屋顶、镜筒对太阳。

## 人物

* 高桥悠介 y，高二：校刊排版，有游戏和设计杂志兴趣，朋友中村。会嘴硬、逞强、被拒绝和生气，不是无限有空的助手，也不能全知解说别人的心理。
* 藤野遥 h，高二：短深紫发、青绿眼睛，负责目视观测和接待，喜欢小说，考虑日本文学。可靠不等于永远体贴；恋爱时会期待独占相处，会因失约不高兴。不要只写交接工作。
* 小原千夏 c，高二：栗色长发、琥珀眼睛，摄影，和悠介原本同级相识。敢夸自己的作品，会逗人。课程：一月10日公开活动，正式六个周六1/17、1/24、1/31、2/7、2/14、2/21；三月22日课程作品展。水野p是成年同学，不是可攻略人物，摄影教师pc给具体反馈。摄影公开用途要说明，但别让每场都变许可讲座。
* 佐伯凛 r，高一：棕色马尾、绿眼，活跃、好胜、怕被当小孩。想邀请原班朋友来看自己喜欢的天空；会出错和逃避，也能主动提出约会。感情不建立在男主教她一切的上下级关系上。
* 朝仓灯里 a，高二：深蓝黑长发、灰蓝眼睛，修旧支架、做小型观测辅助装置；干涩幽默，手很稳，说不好时会伤人。已是天文部成员，别写成突然新转学生。她可以一直喜欢幕后和工具，结局不要求她变成热闹外向的人。
* 冈本航 o，高三前部长：准备升学、三月6日毕业，会偷懒和忘事；不把他写成万能成熟前辈。
* 森田 m，高一：肯搬器材，有粗心和反应慢的笑点，后来能独立收场。
* 大野 d，高二：试印、纸张与星图兴趣，名字固定“大野”，不写成“小野”。
* 野崎 z，高二：兼乐队排练，录音兴趣，很多时间已另有安排。
* 田边老师 t，顾问，不计社团人数。中村n是悠介原班朋友，不计部员。

悠介入部后九人：y/h/c/r/a/o/m/d/z。冈本毕业后八人；四月见学者暂不计正式人数。各路线未选女主照常学习和活动，不能因未被选而失去生活，也不能四女主都围着悠介起哄。

## 时间与共享事件

g01 10/24第一次开放观测：海报、四人初识、双星；g02 10/27–11/02归还器材并入部；g03 11/03–11/09四种看星方式；g04 11/10–11/21雨天日常和共同目标；g05 11/21–11/28试办月面、能力与时间的限制；g06 11/29–11/30明确选下一次想单独见的人。

s01 12/20–21两天一夜合宿。九人中y/h/c/r/a/m六人过夜，野崎白天来；冈本与大野不过夜，田边另计。天气有云、部分目标看到；有人拍失败、凛找到目标、牌局没及时结束，人与人的关系在这些细事里变化。

s02 1/05冬季试办。先前预约的同学来，分工尝试和现场反馈具体，之后大家一起吃东西/走走；不是整章开会议。千夏仍有1/10公开活动邀请；遥仍有文学兴趣；凛有同龄朋友；灯里的小装置可以不完美。

s03 3/06毕业与交接。九份原先的记录，有一份由冈本带走，学长不是失踪或病故。清点、合照、闲话和私下告别，给不同路线留空间。

s04 3/21春季公开观测。所有人完成此前约定，外部来访者如约来；预约人数不凭空翻倍。先按晴空窗口看低倍目标，云多时有演示/记录册。千夏已在3/20完成主要布展，3/22才正式作品展，不制造“同日只能选一个”的假矛盾。遥有自己的观察时段、凛带自己的小组、灯里做现场器材支持。每条路线可有私人片刻，不能让别的女主成为恋爱失败者。

四月6日：高二升高三，凛升高二，冈本毕业；新生进入，四线各自下一次约见的承诺应具体。

## 避免与必须兑现

没有超自然/绝症/强迫亲密/攻略锁。保留笨拙和真实争执，不用长篇解释谁有多成熟。日期、过夜人数、工具来源、相机携带、称呼随关系一致。跨线共享事件由同一份正文实现，不在各线改写出互相矛盾的版本。

补充固定事实：凛生日2/11（2026年16岁，当天为学校假日）；3/3皆既月食为真实天象，参考国立天文台，个别私密观测留在个人线。千夏3/20已完成主要布展，3/21晚回学校观测，3/22正式展。灯里的十二月红灯握套与一至三月手动演示支架是两件不同项目。
