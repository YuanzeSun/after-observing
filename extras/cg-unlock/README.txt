观测结束以后：可选 CG 解锁补丁

含全部插画剧透。适用于 Windows / Linux 1.1、1.1.1。
只想按剧情逐步收集插画的玩家无需安装。

安装：
1. 完全退出游戏。
2. 将补丁内的 game 文件夹合并到游戏安装目录的 game 文件夹。
   最终应为 game/zz_after_observing_cg_unlock.rpy，不是 game/game/。
3. 重新启动游戏，打开「回想与鉴赏」→「事件插画」。
   32 张插画均可直接打开，不需要先读完剧情。

补丁不含玩家存档，不会添加存档槽，也不会删除或替换你的现有存档。
未开始游戏的新玩家，读取存档页面仍为空。
已读章节、路线完成情况、选项前情、摄影作品与音乐鉴赏均不受影响。

移除补丁：退出游戏，删除 game/zz_after_observing_cg_unlock.rpy
以及同名 .rpyc（如果已经生成）。已经记入鉴赏页的插画会保留解锁。
请不要为撤销补丁而删除 persistent；那会丢失其他鉴赏与阅读记录。

save-baseline.zip 是开发者构建数据，不是玩家存档或解锁补丁，请勿安装。
